// What are asynchronous operations and API responses in JavaScript?

Asynchronous operations allow JavaScript to perform tasks such as fetching data from a server without blocking the execution of other code.

Common concepts include:
- Promises: Represent the eventual success or failure of an asynchronous operation.
- async/await: Makes asynchronous code easier to read and manage.
- Fetch API: Sends HTTP requests to a server and retrieves data.
- API responses: Contain information returned by a server, including status codes and data.

//Example:

async function fetchUsers() {
    try {
        const response = await fetch(
            "https://jsonplaceholder.typicode.com/users"
        );

        if (!response.ok) {
            throw new Error("Failed to fetch users");
        }

        const users = await response.json();
        console.log(users);
    } catch (error) {
        console.error("Error:", error.message);
    }
}

fetchUsers();
