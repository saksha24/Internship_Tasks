1. Functional Components
1. Functional components are JavaScript functions that return JSX to display UI elements.
2. They are used to create reusable parts of a React application.
3. Functional components can accept data through props.
4. They use hooks like useState to manage state.
5. They make React code simple, readable, and easy to maintain.

2. Props and State
1. Props are used to pass data from a parent component to a child component.
2. Props are read-only and cannot be directly modified by the receiving component.
3. State stores data that can change during a component's execution.
4. When state changes, React re-renders the component to update the UI.
5. Props are used to share data, while state manages changing data within a component.

3. useState Hook
1. useState is a React hook used to manage state in functional components.
2. It returns an array containing the current state value and a setter function.
3. It is imported from the React library.
4. The setter function updates the state value and triggers a re-render.
5. Example: const [count, setCount] = useState(0);

4. Event Handling
1. Event handling allows React components to respond to user actions.
2. Common events include onClick, onChange, and onSubmit.
3. Event handlers are written using camelCase naming conventions.
4. Functions are passed to event handlers using curly braces.
5. Example: <button onClick={handleClick}>Click Me</button>

5. Controlled Components
1. Controlled components are form elements whose values are managed by React state.
2. They commonly use the value or checked prop.
3. The onChange event updates the state when the user enters or changes data.
4. They provide better control over form inputs and validation.
5. They are commonly used for text fields, checkboxes, and dropdowns.

6. Form Handling
1. Form handling is used to collect and process user input.
2. React forms commonly use controlled components to manage input values.
3. The onSubmit event handles form submission.
4. event.preventDefault() prevents the browser's default form submission behavior.
5. Form data can be validated and submitted to a server through an API.

7. Conditional Rendering
1. Conditional rendering displays UI elements based on specified conditions.
2. The if-else statement can determine which content a component returns.
3. The ternary operator (condition ? A : B) displays one of two alternatives.
4. The logical AND (&&) operator displays an element when a condition is true.
5. It is useful for showing loading messages, error messages, and login or logout views.

8. Basic Form Validation
1. Form validation checks whether user input meets specified requirements.
2. Required-field validation ensures that important fields are not empty.
3. Email validation checks whether an email address follows an acceptable format.
4. Length and pattern validation check input against specified rules.
5. Validation messages help users correct errors before submitting the form.
